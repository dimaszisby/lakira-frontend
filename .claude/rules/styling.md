# Styling and Design Tokens

Canonical references: [`docs/reference/style/color-palette.md`](../../docs/reference/style/color-palette.md), [`docs/reference/style/typography.md`](../../docs/reference/style/typography.md), [`docs/reference/components/component-styling-tailwind-and-tokens.md`](../../docs/reference/components/component-styling-tailwind-and-tokens.md).

Tailwind 3 (not v4) with a six-layer CSS-variable token system.

## The layers

Import order in `src/styles/globals.css` is load-bearing. A token file imported out of order gets overridden by the layer that should have been beneath it.

```
palette → semantic → scales → typography → component tokens → component recipes
→ @tailwind base/components/utilities
```

1. **`tokens/palette.css`** — raw brand colours, no UI meaning. Stored as **bare HSL bodies** (`348 69% 86%`, no `hsl()` wrapper) so Tailwind can apply `<alpha-value>`. Families: `sakurapink`, `matchagreen`, `softwhite`, `origamiblue`, `lightpeach`, `washigray`, `vividcoral`, `goldenyellow`, `softlavender`, `info`, plus a twelve-step gray ramp.
2. **`tokens/semantic.css`** — UI meaning, theme-switched. `--bg`, `--surface`, `--surface-2`, `--text`, `--text-secondary`, `--text-tertiary`, `--text-inverted`, `--text-error`, `--border`, `--ring`, `--input-bg`, and status triads (`--status-error`, `-bg`, `-emphasis` — same for success/warning/info). Defined for `:root, :root[data-theme="light"]`, overridden under `:root[data-theme="dark"]`. Dark mode flips surfaces, text, border, and input only; status colours deliberately inherit.
3. **`tokens/scales.css`** — `--space-1..7`, `--radius-xs/sm/md/lg`, `--shadow-sm/md`, and button geometry.
4. **`tokens/typography.css`** — font smoothing, base element defaults, and the semantic text classes (`.text-body1`, `.text-caption`, `.text-button`, `.text-link`, …).
5. **`tokens/components/<x>.tokens.css`** — per-component variant→palette mapping, in `@layer base`.
6. **`tokens/components/<x>.recipe.css`** — the `.x` class plus `[data-variant]` / `[data-size]` selectors, in `@layer components`.

## Hard rules

- **Never write a raw hex or `rgb()` in a component.** Use a semantic Tailwind class — `bg-surface`, `text-ink-secondary`, `border-border`, `ring-ring`, `text-status-error`.
- **Never reference a palette variable from a component.** `--primary-sakurapink-500` is layer 1; components consume layer 2 or layer 5. If no semantic token expresses what you need, add one to `semantic.css` rather than reaching past it.
- **Never write an arbitrary font size.** Use the named scale — `text-h3`, `text-body1`, `text-caption` — not `text-[28px]`. The scale in `tailwind.config.mjs` is named, not numeric, and each entry carries its own line height.
- **Never hardcode spacing that a scale covers.** `--space-1..7` maps to the Tailwind spacing utilities.
- Theme switching is `data-theme` on `<html>` (`darkMode: ["class", '[data-theme="dark"]']`, driven by `next-themes` and `src/app/ThemeScript.tsx`). A bare `.dark` class does nothing.
- Merge classes with `cn()` from `src/lib/cn.ts`. Never concatenate class strings.

## Adding a component's styles

Follow the two-file pattern:

```
src/styles/tokens/components/badge.tokens.css   → @layer base, variant→token mapping
src/styles/tokens/components/badge.recipe.css   → @layer components, .badge + [data-variant]
```

Register both in `globals.css` in the correct position. Drive variants with `data-variant` / `data-size` attributes rather than conditional class strings, and use the fallback-chain pattern from `button.recipe.css`:

```css
.badge { background: hsl(var(--badge-bg, var(--surface)) / 100%); }
.badge[data-variant="danger"] { --badge-bg: var(--badge-danger-bg); }
```

## Known token-system defects

- **`--text-emphasis` is referenced but never defined.** `tailwind.config.mjs` maps `ink.emphasis` to it, so `text-ink-emphasis` resolves to nothing. Either define it in `semantic.css` or stop using the class.
- **`src/styles/temp.css` and `src/styles/output.css` are stale artifacts.** `output.css` is generated by `build:css` and is not part of the normal build. Do not import either.
- `palette.css` carries two "Current vs Figma" drift comments (`matchagreen-100`, `goldenyellow-100`). The CSS is authoritative until someone reconciles them.

## Fonts

`display` = Quicksand, `ui` = Plus Jakarta Sans, both loaded via `next/font/google` in `src/app/layout.tsx` with `display: "swap"`. Do not add a font without a performance justification — see `.claude/rules/performance.md`.

## CSS lint

`npm run lint:css` runs Stylelint over `src/**/*.{css,pcss}` as a separate CI gate. `format-on-edit.sh` runs `stylelint --fix` after every CSS edit.
